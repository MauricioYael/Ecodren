ECODREN es un sistema Hidroneumático diseñado para la limpieza y desazolve de drenajes
Ecodren ED-17

Acción simultanea de succión y presión con tecnología avanzada para operaciones mas rápidas, seguras y con un menos consumo de agua y combustible.

Bomba ECOJET exclusiva

  • Aplicación: Diseñado para alcantarillado
  • Operación Opera bajo desgaste
  • Rendimiento: Presiones de hasta 3,000 PSI

Tanque de desechos reforzado

  • Material: Tanque fabricado en acero de alta resistencia
  • Versatilidad: Capacidades de 3 yd a 17 yd

Carrete y manguera frontal

  • Mecanismo: Movimiento telescópico
  • Cobertura: Rotacion hasta 270° para maxima accesibilidad

Seguridad y ergonomía

  • Distribución: Controles frontales
  • Protección: Paros de emergencia
  • Enfoque: Diseño orientado al operador

Sistema de vacío avanzado

  • Potencia: Compresor centrífugo o soplador PD
  • Higiene: Filtrado multietapa profesional

Tecnología inteligente

  • Monitoreo: Panel electrónico de diagnostico
  • Control: Seguridad y monitoreo de operation
